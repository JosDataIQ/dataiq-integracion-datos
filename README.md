# DataIQ - Repositorio de Integración de Datos

Repositorio central de código técnico para POCs y demos de:
- Snowflake
- Qlik Talend Cloud
- Qlik Replicate
- Talend Studio

> Documentación comercial, propuestas, cuestionarios y presentaciones 
> viven en [Drive - Repositorio Demos](https://drive.google.com/drive/folders/10H0oa1-YbSIC09GeG2l4Iiyd8uiSsR17).
> Este repo contiene solo código y configuraciones técnicas.

## Estructura
- `/snowflake` — scripts SQL, Streamlit apps
- `/qlik-talend-cloud` — configs y documentación de pipelines
- `/qlik-replicate` — sizing y configuraciones
- `/talend-studio` — jobs (.item) y exports

## Cómo contribuir
Cada carpeta de POC tiene su propio README con contexto y link a la demo/ambiente vivo.
